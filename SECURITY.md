# Security policy

Oger Dock is a KDE Plasma widget with native C++ integration and user-session permissions.

## Reporting a vulnerability

**Do not open a public issue with exploit details or personal information.** Use the GitHub repository's private vulnerability reporting feature if enabled. If it is unavailable, open a [Discussion](https://github.com/dsrsouza/Oger-Dock/discussions) requesting a private contact channel **without sharing exploit details**.

## Supported versions

| Version | Security fixes |
|---|---|
| 1.0.x | Current release line; updates provided as resources permit |
| Development revisions R63.x | Superseded by 1.0.x |

Avoid executing arbitrary installation scripts from unverified mirrors. Check the integrity hashes supplied with release archives and review changes before granting elevated privileges.

This policy does not guarantee a response time or imply a completed security audit.
