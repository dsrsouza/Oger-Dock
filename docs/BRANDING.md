# Oger Dock — Visual identity / Identidade visual

Official visual identity is based on the **ogre mascot** used by the Oger Dock application.

## Official assets

| Asset | Purpose |
|---|---|
| [Oger logo](../Images/oger-logo.png) | Header and small GitHub icon (optimized preview) |
| [Brand cover](../Images/oger-brand-cover.svg) | README display / presentation graphic |
| `contents/images/oger-dock-widget.png` | Full-resolution application logo (part of the source installer, available after source import) |
| `contents/images/oger-menu-symbolic.png` | Symbolic menu icon in the source installer |

The brand cover is **graphic identity**, not a screenshot. Real application screenshots belong in the [screenshot guide](SCREENSHOTS.md) and must be labeled by functionality.

## Usage / Uso

- Keep mascot proportions; do not stretch or rotate it.
- Retain transparent background for the icon.
- Use readable contrast on dark and light GitHub themes.
- Do not substitute artwork from Punchi Dock Remastered for Oger Dock screenshots.
- Preserve authorship and licensing notices in the source distribution.
